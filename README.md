Python Programming – 5 Modules

About This Repository 
This repository contains Python programs completed as part of my academic coursework. It includes basic Python concepts, problem-solving programs, data structures, file handling, and mini-projects across five modules.

Module 1 – Python Basics Programs based on basic calculations and mathematical operations.
"basic_calculator.py" – Performs basic arithmetic operations.
"electricity_bill_generator.py" – Generates electricity bills.
"mathematical_operations.py" – Performs mathematical operations.
"student_marks_report.py" – Calculates and displays student marks reports.

Module 2 – Control Statements and Loops Programs based on loops, conditions, and number operations.
"Fibonacci_series.py" – Generates the Fibonacci series.
"Guessing_no.py" – Number guessing game.
"OTP_generator.py" – Generates random OTPs.
"factorial.py" – Calculates the factorial of a number.
"prime_no.py" – Checks prime numbers.

Module 3 – Functions and Data Structures Programs based on functions, lists, dictionaries, and data management.
"contact_book.py" – Manages contact information.
"frequency_counter.py" – Counts the frequency of elements.
"project_attendence_tracker.py" – Tracks project attendance.
"student_grading.py" – Calculates student grades.

Module 4 – File Handling and Data Processing Programs based on files, CSV, JSON, and data management.
CSV Based Payroll Management – Manages payroll information using CSV files.
"Log_file_reader.py" – Reads and processes log files.
"Student_data_manager.py" – Manages student data.
"json_based_log_file_analyzer.py" – Analyzes log files using JSON.

Module 5 – Python Mini Projects Practical projects applying Python programming concepts.
"bank_account_system.py" – Simulates basic banking operations.
"dice_simulator.py" – Simulates rolling a dice.
"library_management_system.py" – Manages library records.
"retail_sales_dashboard.py" – Displays and analyzes retail sales data.
"Data/" – Contains supporting project data files.
